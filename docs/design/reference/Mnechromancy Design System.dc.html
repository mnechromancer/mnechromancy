Behavioral rules
core — the identity at full expression. Dial highlights, markers, swatches. Never behind text. field — the constrained luminance envelope: L 0.32–0.50, C ≤ 0.11. Everything text sits on — the radial field, button fills, selected states. White text ≥ 5:1 on the worst case, so 4.5:1 holds on every triad. tint / shade — colored text and numerals on dusk / dawn chrome respectively. line — hairlines, ticks, borders. Butt caps, 1px. the ramp — core L runs 0.55 → 0.85, field L 0.32 → 0.50, monotonic Red → Violet. Position lives in luminance, not only hue, and the ascending ramp mirrors the ascending pitch scale (§6). The palette editor warns below ΔL 0.03.

Consonance tracks scope conflict: a Red day in a Red Hand is a unison; a Yellow day in a Red Hand is an interval with real friction in it. Dusk plays the lived color against the assigned one.

Silence is first-class — muting never costs information. Short, quiet, never on cold launch. Synthesis, not samples. The hum sustains the chord under the interface, each voice slowly swelling and fading on its own period. Newton and Scriabin presets are transcribed from source at implementation, not invented.
